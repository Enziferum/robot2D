# VIEW-01: Toolbar и SlateTeal

Первый согласованный шаг [VIEW-01 #49](https://github.com/Enziferum/robot2D/issues/49),
реализацию ведёт ассистент по поручению пользователя 2026-10-16.
Общий маршрут — [project-roadmap.md](project-roadmap.md).

## Поведение

- Move / Scale / Rotate используют один уже подключённый шрифт Font Awesome,
  активный инструмент выделяется цветом темы; прежние shortcut сохранены.
- Grid включает/выключает существующую экранную сетку только Scene Viewport.
  Рисунок существующей сетки не меняется; мировую сетку этот шаг не реализует.
- Snap независим от Grid. Шаг Move/Scale — 16 единиц по умолчанию, Rotate — 15°.
  Меню `...` задаёт оба шага. Это квантизация смещения от начала drag, а не
  принудительное выравнивание начальной позиции на мировую сетку.
  Мелкие движения накапливаются. Пока drag активен, настройки Snap и камера
  через Toolbar недоступны; смена настроек программно отменяет drag.
- Frame Selected охватывает bounds выбранных валидных TransformComponent,
  включая текущие повороты. Без выделения кнопка недоступна.
- Меню масштаба: 25/50/100/200/400/800% и Frame scene. Frame scene охватывает
  сущности с TransformComponent, включая камеры и невидимые объекты.
- 100% — одна единица сцены на пиксель viewport; коэффициент ограничен 5–800%.
  Frame добавляет запас 25%; для экстремально больших/малых bounds полный fit
  ограничен диапазоном zoom. Нулевые bounds центрируются с ограниченным zoom.
- Ctrl+wheel показывает накопленный абсолютный zoom. Изменение масштаба и
  resize сохраняют центр. Reset из существующей панели сбрасывает zoom в 100%
  и центр в середину viewport. До появления валидного размера действия безопасны.
- Новые 2D-контролы отключены для перспективной камеры. На узкой панели
  дополнительные контролы переносятся на следующие строки.
- SlateTeal применяется при запуске и подготовке редактора. SlateBlue, GoldBlack
  и UE4 сохранены. Цвета и метрики темы задаются централизованно через applyStyle.

Настройки Toolbar действуют в текущей сессии. Выбор темы из MenuBar и его
сохранение, превью текстур и дерево Assets не входят в этот шаг. Существующие
групповые трансформации и Undo-контракт не перерабатывались.

## Ручной сценарий приёмки

1. Запустить редактор из сборки VIEW-01 и открыть существующую сцену.
   Проверить SlateTeal, подписи, выбранный инструмент и tooltip.
2. Выключить Grid: исчезает только сетка Scene Viewport; Game View не меняется.
   Включить Snap при выключенной сетке: оба переключателя независимы.
3. С шагом 16 двигать объект короткими движениями: смещение накапливается,
   после порога применяется шаг; выключить Snap и проверить плавный drag.
   Повторить на X/Y/XY, Scale и Rotate с шагом 15°.
4. Выделить одиночный, повёрнутый и несколько объектов, нажать Frame Selected.
   Проверить fit с запасом. Без выделения кнопка отключена; Frame scene работает.
5. Выбрать 50/100/200%, изменить размер viewport и проверить сохранение центра.
   Проверить Ctrl+wheel и Reset. 100% сверить с объектом известного размера.
6. Сузить docked viewport, проверить перенос контролов, tooltip и меню Snap/zoom.
   Проверить, что нажатия Toolbar не выбирают объекты сцены.
7. Во время drag отпустить мышь за пределами viewport либо переключить окно.
   После возвращения drag не продолжается. Проверить выбранные корни и дочерние
   объекты, сохранение/повторное открытие сцены без неожиданных трансформаций.

Следующий шаг — ручная приёмка и ревью PR. После неё отдельно согласовать
превью текстур и дерево Assets; оставшиеся критерии VIEW-01 не закрываются
автоматически по этому первому шагу.
