# Сайт robot2D — WEB-02

Задача [#133](https://github.com/Enziferum/robot2D/issues/133), отдельная ветка WEB-02
от удалённого dev ab0f3a5. Проект в [website/](../website/README.md), Astro + Starlight,
английский язык, SlateTeal. Главная, Features, Showcase, Downloads, Releases,
Roadmap, 404 и вводная документация /docs/. Это первый локальный вариант сайта;
хостинг и публичная публикация не настроены.

## Материалы и достоверность

Пользовательский кадр Robot Lab с превью текстур сохранён как исходный PNG;
WebP используется для загрузки страницы, manifest содержит SHA-256 и происхождение.
Кадр показывает редактор d77dff3cbd56 с изменениями ASSET-01, ожидающими интеграции,
а не опубликованный v0.7. Игровой арт сгенерирован, UI на скрине настоящий.

Версия разработки берётся из корневого CMakeLists.txt. История релизов —
проверяемый JSON-снимок GitHub Releases, обновляемый явной командой maintainer.
Первоначальный снимок до 0.8.0 сохранён в docs/archive, вне сайта. Публичный
каталог и команда sync исключают версии ниже 0.8.0; пустой каталог допустим.
Downloads предлагает dev из исходников до появления реального выпуска 0.8+. Готовый installer, standalone demo,
новый публичный релиз, пожертвования и сроки 1.0 не обещаются.

## Приёмка

Команды, конфигурация SITE_URL/SITE_BASE, источники и ограничения проверки описаны
в [website/README.md](../website/README.md). Сборка сайта не требует C++.
CI запускается на pull request по изменениям сайта и проверяет корень и /robot2D/.
Публичный домен задаётся после выбора хостинга; без него sitemap пропускается
с ожидаемым предупреждением. Computer-use и управление браузером не используются.

Ручной сценарий пользователя: главная и Docs на широком/узком экране; навигация
с клавиатуры; открытие исходного скрина; поиск в документации; 404. Следующий шаг —
визуальная приёмка, затем упакованная демка/запись gameplay, утверждение логотипа
и выбор хостинга. WEB-01/#108 и его PR по README остаются отдельной работой.

## WEB-02: первый практический урок Core — 2026-10-17

Опубликован Lesson 01: your first sprite (/docs/core/first-sprite/): окно
800x600 через Engine/Application, загрузка PNG Robot Lab, явные texture rect/size,
пакетная отрисовка и освобождение GL-ресурса до закрытия контекста. Полный код
импортируется в MDX из тех же файлов, которые собирает CMake, без отдельной копии
листинга. Разобраны CWD/asset path, borrowed texture/window, диагностика и упражнение.
Исходный PNG и provenance включены; основной checkout пользователя не менялся.

Опциональная цель robot2D-first-sprite включается RB2D_BUILD_CORE_EXAMPLES=ON,
выход <build>/examples/first-sprite/<configuration> с assets рядом. Это пример
внутри исходного репозитория, не установленный SDK; зависимости root configuration
сохраняются. Native CI собирает его на обеих платформах; Linux graphics job
дополнительно запускает core-lesson.render/missing-texture.

Локально собраны executable и test target; 2/2 graphics-теста прошли без пропусков
в скрытом GL-окне: реальные жёлтые пиксели в границах спрайта, один quad/draw call,
close event, повторное освобождение и missing-texture с абсолютным путём.
Проверяются методы опубликованного приложения, а не управление Engine event loop
или интерфейсом редактора. Python 53/53; сайт test 6/6, Astro check без диагностик,
format:check, build 19 страниц, ссылки 622 для / и 634 для /robot2D/.
Computer-use не применялся; визуальная приёмка видимого окна остаётся пользователю.
Реализация — commit 08b1410 в WEB-02 / PR #134. Обязательный hook прошёл:
сборка редактора/tests, 169/169 CTest и strict clang-tidy 191 единиц; Python 53/53.
Новые удалённые CI runs оцениваются отдельно после push, без переноса старых результатов.
Следующий материал — клавиатурное перемещение; общий DOC-01/GAME-04 не закрываются.
