# RUNTIME-02: падение при переходе Play → Game View

## Диагноз

В RobotLabPlatformer сборка ASSET-01 a0d316f завершилась при первом событии
мыши в Game View. Обычный robot2D.log обрывался после применения сцены,
без записи о Play. Windows Application Error 1000 за 2026-10-16 23:10:40
зафиксировал c0000005, offset 0x94610, PID 34756. Дизассемблирование именно
этого robot2D.exe сопоставило адрес 0x140094610 с UISystem::handleEvents,
первым обращением к полю объекта в ветке MouseMoved.

UISystem наследовал базовый cloneSelf, возвращающий nullptr. SystemManager
пропускал такую систему при клонировании. Scene::handleEventsRuntime затем
вызывал метод через отсутствующий runtime UISystem. Это ошибка самого объекта,
а не дефект PNG или C#-контроллера. В свежем удалённом dev ab0f3a5 причина
также присутствовала; обновления SCRIPT-01/HUD-01/BUILD-01 её не исправляли.

## Исправление

UISystem клонирует системные требования и сущности через cloneBase, сохраняет
камеру и зарегистрированные callbacks. Очереди ввода и координаты мыши остаются
новыми для каждого runtime. Отсутствующая камера не обрабатывает pointer input.
MouseMoved читает event.move, а не неактивный mouse-член union. Проверяются
границы/пустые callbacks; hover-регистрация возвращает индекс своей коллекции.
Core ECS, Snapshot, CancellationToken и полный жизненный цикл runtime не менялись.

## Проверки

Воспроизводящая headless-регрессия editor-runtime-ui на dev ab0f3a5 упала
на отсутствии runtime UISystem до исправления. После исправления проверяет
три клонирования, координаты через камеру, callback, отсутствие унаследованных
событий, отрицательный/слишком большой индекс callback и отсутствие камеры.
Graphics editor-scene-runtime-ui-events проверяет реальный Scene Play/Stop
с MouseMoved/MousePressed/MouseReleased трижды и сохранение editor-сущностей.
Полный CTest после первого исправления: 110/110, включая 43 graphics.
Дополнение invalid-index затем проверяется обязательным hook.

Редактор из RUNTIME-02 на базе ab0f3a5 запускался с RobotLabPlatformer;
сцена открылась, состояние Running наблюдалось. Полный ручной Play, движение,
прыжки, возврат и переключение Game не считаются подтверждёнными: пользователь
остановил computer-use и запретил дальнейшее использование в robot2D.
Ручную UI-приёмку выполняет пользователь по скриншотам/логам. Это правило
записано в AGENTS.md и не требует повторного предложения computer-use.

Следующий шаг: обязательный hook, PR в dev, ручная приёмка пользователем.
Полный RUNTIME-02 #37 остаётся открытым.
