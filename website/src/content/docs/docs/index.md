robot2D is a 2D game engine and visual editor built with C++17. Game behaviour uses C# scripts through Mono. It is an active development project on the road to 1.0.

Start with **Build from source** in the sidebar, then create your first scene. These are introductory guides; the repository documentation remains the detailed engineering reference.

## The basic loop

1. Open or create a project in the editor.
2. Arrange entities and configure components in the Inspector.
3. Add C# behaviour, build scripts, and press Play.
4. Test the scene, stop, and keep editing.

## Before you begin

The current development line is 0.8.0-dev. Published historical releases differ substantially from the development editor shown on this website. No current installer is available in the website release snapshot.

Windows and Linux are development platforms. A GPU and driver supporting **OpenGL 4.5** are required. macOS is not part of the current build guidance.
