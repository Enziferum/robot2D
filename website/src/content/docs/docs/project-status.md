## Development and releases

The current development line is **0.8.0-dev**. A version in the source tree is not automatically a published release. The website release list is a dated snapshot of GitHub Releases; always check GitHub for changes since that date.

The public release catalogue starts with 0.8.0. Screenshots show development work, including changes awaiting integration; only published, checked artifacts belong in Downloads.

## Release goals

- **0.8.0:** create, build and share a small 2D game.
- **0.9.0:** evolve runtime architecture, scene transitions, game UI and audio.
- **1.0.0:** a stable public tool with compatibility, documentation and distribution.

These are goals, not a list of completed features. No release dates are announced here. Track acceptance criteria in the [release roadmap](https://github.com/Enziferum/robot2D/blob/dev/docs/release-roadmap.md) and [issues](https://github.com/Enziferum/robot2D/issues).

## Help the project

Try a development build, report a reproducible problem, improve documentation, or discuss a contribution on GitHub. Include the version, platform, reproduction steps and relevant log when reporting a bug.

The project has not announced paid plans or a donation destination on this website.
