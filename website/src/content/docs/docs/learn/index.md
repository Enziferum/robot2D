Robot Lab is the project's learning example: a small robot explores a laboratory. The course will grow alongside the demo. Start with the scene-reading article below; the complete downloadable course is not published yet.

## Two ways in

- **Use the editor:** begin with [reading a scene](reading-a-scene/), then the [first-scene guide](../first-scene/).
- **Understand the engine:** explore the [Core overview](../core/) and follow the source behind each tool.

## The planned practical path

| Stage                | You will build                             | Publication state                                                         |
| -------------------- | ------------------------------------------ | ------------------------------------------------------------------------- |
| 1. Scene foundations | Camera, player, platforms and colliders    | Scene-reading introduction available; reproducible project lesson planned |
| 2. Movement          | C# controls, grounded movement and jumping | Planned                                                                   |
| 3. Interaction       | An energy cell, a laser and a checkpoint   | Planned                                                                   |
| 4. Feedback          | Sprite animation, camera and HUD           | Planned                                                                   |
| 5. Finish and share  | Win state, full restart and Build          | Planned                                                                   |

Published practical lessons will include a pinned engine version, starting and finished projects, the steps, an observable expected result and a small exercise. A lesson becomes ready after someone reproduces it from its stated starting point.

The [GAME-04 tracker](https://github.com/Enziferum/robot2D/issues/138) holds the course plan under [DOC-01](https://github.com/Enziferum/robot2D/issues/94). It is a gradual effort toward 1.0, not a condition that the entire course must exist before 0.8.0.
